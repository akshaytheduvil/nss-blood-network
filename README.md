# NSS Blood Network

A student-led blood donor coordination platform for the NSS unit of
**PPTM Arts & Science College, Cherur**.

## Live Site

🌐 [akshaytheduvil.github.io/nss-blood-network](https://akshaytheduvil.github.io/nss-blood-network/)

## Features

- 🩸 Donor registration with blood group, location, and availability
- 🔎 Authenticated donor search by blood group
- 📞 One-tap call button (donor phone numbers hidden)
- 📖 Donor guidelines — eligibility, prep, process, aftercare
- 🏅 Certificate of appreciation (A4 landscape, print-ready)
- 📊 Live statistics on the homepage

## Tech Stack

- HTML5, CSS3, vanilla JavaScript
- Firebase Firestore (database) + Firebase Auth (admin login)
- Hosted on GitHub Pages

## Purpose

This project was created as part of the NSS unit's community-service
initiative to organize voluntary blood donation within the college
community and make donor coordination faster and more reliable.
